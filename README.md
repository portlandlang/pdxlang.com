# pdxlang.com

Sends [pdxlang.com](https://pdxlang.com) to [portlandlang.com](https://portlandlang.com), the home of [Portland](https://github.com/portlandlang/portland).

Two static pages with a meta refresh: `index.html` for the root, and `404.html` so any other path lands in the same place. GitHub Pages serves them straight from `main`, with no build step (`.nojekyll`), and provides the HTTPS certificate for pdxlang.com.
